# VoyageVista

VoyageVista est une application web de gestion de voyages permettant aux utilisateurs de consulter des destinations, des offres de transport, des hébergements et des activités.

## Objectif du projet

L’objectif du projet est de proposer une plateforme simple et claire pour organiser un voyage à partir de plusieurs services :

- destinations ;
- transports ;
- hébergements ;
- activités ;
- réservations.

## Architecture générale

Le projet est organisé en plusieurs parties :

- `index.html` : page principale du site ;
- `css` : fichiers de style et mise en page ;
- `js` : scripts JavaScript pour les interactions côté client ;
- `backend` : fichiers PHP pour la logique serveur ;
- `pages` : pages secondaires du site ;
- `base_de_données.sql` : script SQL de création ou de mise à jour de la base de données.

## Fonctionnement général

L’utilisateur navigue sur le site depuis l’interface frontend. Les pages permettent d’afficher les offres disponibles et d’accéder aux différentes fonctionnalités du projet.

Le backend PHP permet de gérer la partie serveur, notamment la connexion, les traitements liés aux réservations et les échanges avec la base de données.

La base de données permet de stocker les informations nécessaires au fonctionnement de la plateforme : utilisateurs, destinations, réservations et services proposés.
